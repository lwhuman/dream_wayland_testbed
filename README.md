# dream_wayland_testbed
This repository is used as a testbed to test, develop and experiment with the Wayland backend of DreamFoundation's windowing system, before integrating into the main codebase. This allows rapid prototyping of backend features without needing to constantly add and compile experimental wayland-specific code in the main library codebase, avoiding unnecessary development friction. Code is only ported to the main repo once a API is fully tested and stabilized.

## Build Instruction

### Requirements:
- wayland-scanner
- wayland-protocols
- libwayland-client
- wayland-client headers
- gcc/clang
- make (*optional*)
- cmake (*optional*)
- python3 (*optional*)

### Build:
To generate glad opengl loader and headers:
```bash
git submodule update --init --recursive
python3 setup.py
```

This is optional since opengl loader and header generated by glad is shiped within the codebase. So it can be skipped.

Then build by:
```bash
mkdir build && cd build
cmake ..
make
```

## Use this in your project

If you want to quickly built a wayland native client application window, then you can just use this codebase in your project.

#### Using git submodules and cmake:

Add this repo as a git submodule:
```bash
git submodule add https://github.com/lwhuman/dream_wayland_testbed.git external/WayClientLib
git submodule update --init --recursive

```
Add the following in your project's CMakeLists.txt:
```cmake
set(BUILD_TESTS OFF)
set(DREAM_WAYCLIENTLIB_DIR ${CMAKE_BINARY_DIR}/dwclib_build)

```

Finally link your executable/target with libwayclient.a:
```cmake
target_link_libraries(your_target PRIVATE wayclient)

```
